## [1.0.0] - 2026-08-17

### Added

- Thirteen executable Codex agent definitions with one primary responsibility
  each.
- Adaptive orchestration across product discovery, user research, UX/UI design,
  architecture, data, implementation, quality, security, delivery,
  documentation, reliability, and release management.
- Seven evidence-based delivery gates from intake through human release approval.
- Bounded parallel execution for independent assignments.
- Structured, durable handoffs with scope, evidence, risks, decisions, approval
  state, and correction tracking.
- Independent verification and security review responsibilities.
- Human approval gates for production changes, destructive actions, sensitive
  external writes, material costs, and high or critical risk acceptance.
- Repository-level Git, safety, autonomy, and routing policies.

### Changed

- Consolidated operational documentation into a professional English-only
  project structure.
- Replaced learning-oriented and duplicate role documents with executable agent
  configurations as the single source of truth.
- Expanded the orchestrator to route all specialists, enforce gate evidence, and
  escalate repeated correction failures.

### Security

- Isolated review and coordination roles with read-only workspaces where write
  access is unnecessary.
- Required secret redaction, least privilege, traceable evidence, and explicit
  human risk acceptance across the fleet.
